# Nusantara Tech - Company Profile

Website company profile sederhana yang dibuat sebagai Tugas Praktikum 4 menggunakan Next.js (App Router) dan Tailwind CSS.

🔗 **Live Demo:** [https://535269015-tugas4-praktikum-fron-end-eight.vercel.app](https://535269015-tugas4-praktikum-fron-end-eight.vercel.app)

## Fitur

- Website multi-halaman (Beranda, Tentang, Layanan, Kontak)
- Dynamic routing untuk detail layanan (`/services/[slug]`)
- Reusable components (Navbar, Footer, Container, PageHeader, ServiceCard)
- Navigasi menggunakan komponen `<Link>` bawaan Next.js
- Active link styling pada Navbar
- Tampilan responsif (mobile, tablet, desktop)

## Teknologi

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)


## Menjalankan Secara Lokal


git clone https://github.com/MarvelcoW/535269015_Tugas4_PraktikumFronEnd
cd company-profile
npm install
npm run dev


Buka [http://localhost:3000](http://localhost:3000) di browser.
